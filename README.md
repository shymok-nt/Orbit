# ORBIT

**Find your people. Build your universe.**

ORBIT is a creative, community-first social platform. This repository starts as a Next.js frontend foundation and will grow in reviewed, testable phases.

## Requirements

- Node.js 20.9+ (Node.js 22 LTS recommended)
- npm

## Local development

```powershell
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks

```powershell
npm run typecheck
npm run lint
npm run build
```

## Current scope

**Phase 1A:** initial application skeleton, TypeScript strict mode, Tailwind CSS, design palette and a responsive placeholder landing page. No accounts, database, or persistent social features yet.

Read `docs/ROADMAP.md` and `docs/ARCHITECTURE.md` before extending the project. Do not commit secrets or `.env` files.
