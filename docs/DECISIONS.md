# Architecture Decision Log

## ADR-001 — Next.js App Router and TypeScript

Use Next.js with strict TypeScript for a web-first foundation and gradual feature expansion.

## ADR-002 — Modular monolith

Favor explicit feature boundaries over premature microservices.

## ADR-003 — Creative Social visual identity

Light-first cream, coral, lavender, ink and sand palette. Expand to semantic tokens in Phase 1B.

## ADR-004 — Phase gates

Require a successful local check and user approval before moving into subsequent phases. Changes should preserve existing working behavior.
